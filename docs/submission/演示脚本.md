# 演示脚本（90 秒录屏）

> 目标：让评委在 90 秒内看懂「记忆 → 图谱 → 日程 → 复盘 → 回写」这条闭环。
> 录制建议：手机模拟器或浏览器全屏，字号 100%，关闭通知；旁白语速放慢，别念界面文字。

---

## 准备（录之前）

1. 起服务：`npm run agent`（`.env` 里配好 `DEEPSEEK_API_KEY`）
2. 起 App：`npm run web`
3. **清空数据**：设置页 →「清空我的数据」→ 回到对话页
   （这样录出来是真实从零开始，不是演示数据）

---

## 分镜

### Scene 1 · 0:00–0:12｜从零开始

**操作**：打开 App，进入三问引导。

- 第 1 问「怎么称呼你？」→ 输入 `小林`
- 第 2 问「最近在忙什么？」→ 输入 `准备英语六级`
- 第 3 问「现在最想实现的一个目标？」→ 输入 `三个月内找到 Agent 方向的实习`
- 点「完成，开始使用」

**画面**：图谱页出现「我」+ 两个节点，两条连线。
**旁白**：
> 大多数人用 AI 的第一句话是"帮我写个计划"，但 AI 不知道你是谁。KnowMe 的第一步不是回答，而是先认识你——这三句话，会变成它对你的第一层理解。

---

### Scene 2 · 0:12–0:30｜一句话变成记忆

**操作**：对话页输入

> 我认识了一个叫陈晨的同学，他在做机器人

**画面**：Agent 回复「记住了，陈晨是做机器人的同学。」+ 一张记忆确认卡（类型：人物，置信度 0.9，来源：今天的对话）。点「确认」。

**旁白**：
> 注意，它不是回一句话就完了——它把这句话抽成了一条结构化记忆：人物、关系、来源。**确认之后才会写进图谱**，没确认的一律不进。

---

### Scene 3 · 0:30–0:45｜目标、日程、图谱是同一份数据

**操作**：输入

> 明天下午三点复习高数两个小时

**画面**：任务确认卡 → 点确认 → 切到「成长」页，明天的日程里出现这一条；再切到图谱，出现「复习高数」节点。

**旁白**：
> 一条记忆确认后，日程和图谱是同时更新的——因为它们读的是同一份数据，不存在"三套数据互相对不上"。

---

### Scene 4 · 0:45–1:00｜执行产生真实进度

**操作**：成长页勾掉这条任务。

**画面**：任务变完成 → 本周学习时长 +2h → 目标进度条前进。

**旁白**：
> 完成不是打个勾就完了：它同时生成一条学习事件、写一条记忆、推进目标进度。复盘页的数字全部来自这些真实事件，不是估算。

---

### Scene 5 · 1:00–1:18｜闭环：复盘 → 下周计划

**操作**：点进「本周复盘」→ 滑到「把复盘变成下周动作」→ 点「生成下周计划」。

**画面**：回到成长页，下周日程多出两件事（推进 + 复盘）。

**旁白**：
> 这是 KnowMe 和普通待办最不一样的地方：复盘不是终点。它会围绕你的目标，把结论直接排进下周的日程——闭环是能走回去的。

---

### Scene 6 · 1:18–1:30｜数据一致性（差异化演示）

**操作**：图谱页 → 点「陈晨」节点 → 详情里显示「来源：2026年11月6日 与 Agent 的对话」→ 删除该节点。

**画面**：节点消失，对应的记忆也从记忆列表里消失。

**旁白**：
> 每条记忆都能追溯来源，也能被真正删掉——删节点、删记忆、删目标是双向一致的，不会留下点不进去的"幽灵记忆"。

**收尾字幕**：
> KnowMe 知我 · 记住你的过去，理解你的现在，陪你走向未来
> github.com/zrchen-ops/KnowMe--

## 备用镜头（时间富余时加）

| 场景 | 操作 | 看点 |
|---|---|---|
| 情绪不落记忆 | 输入「我压力好大」 | 只回应，不弹确认卡（说明"克制"） |
| 重复目标归并 | 再说一次「我想通过英语六级」 | 目标不重复，进度不清零 |
| 高风险不执行 | 输入「帮我订明天去上海的高铁票」 | 只回应并提示需要确认 |

## 口播全文（可直接照读，约 260 字）

> 大家好，这是 KnowMe 知我。
>
> 大多数 AI 产品是"你问、它答、然后忘掉"。KnowMe 想验证另一件事：AI 能不能先认识你，再帮你。
>
> 你只需要说三句话，它就建立了对你的第一层理解。之后每你说一件事，它会先抽成一条结构化记忆——人物、目标、日程、事件——**你确认之后，才会进入你的个人图谱**。
>
> 确认的那一刻，日程、图谱、目标会同时更新，因为它们共享同一份数据。你完成任务，它记录真实时长、推进目标进度；每周复盘，它把结论直接变成下周的计划。
>
> 每条记忆都能追溯到"哪天哪句话"，也能被真正删掉，删得干净。
>
> 这是 KnowMe：不是更会聊天的 AI，而是逐渐理解你、记住你、并能在你授权范围内替你行动的个人智能系统。
