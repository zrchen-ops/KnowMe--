## 五、部署方案（如果比赛要求"可访问链接"）

当前架构分两部分，部署要分开：

| 部分 | 建议 | 说明 |
|---|---|---|
| App（静态 Web） | Vercel / Netlify / GitHub Pages | `npx expo export -p web` 产物在 `dist-web/`，直接拖上去 |
| Agent 服务 | Render / Railway / 自己的服务器 | `node server/index.ts`，配 `DEEPSEEK_API_KEY` |

⚠️ 两个坑：

1. **部署后要设环境变量**：App 侧 `EXPO_PUBLIC_AGENT_API_URL=https://你的服务域名`（构建时注入，改完要重新构建）；服务侧 `DEEPSEEK_API_KEY` + `HOST=0.0.0.0`。
2. **服务端一定要限制来源**：现在是 `Access-Control-Allow-Origin: *`（开发方便），上线前改成你的域名，否则别人可以白嫖你的 key。
